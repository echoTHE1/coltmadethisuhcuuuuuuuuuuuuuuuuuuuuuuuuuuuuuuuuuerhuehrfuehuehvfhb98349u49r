# 🚀 NEONPLAY GitHub Pages - 5-Minute Setup Cheat Sheet

## Deploy in 5 Minutes

### Step 1: Commit Everything (2 min)
```bash
git add .
git commit -m "🔓 NEONPLAY - GitHub Pages optimized & ad-blocker safe"
git push
```

### Step 2: Enable GitHub Pages (1 min)
1. Go to **Settings** (top right)
2. Click **Pages** (left sidebar)
3. Choose: **Deploy from a branch**
4. Select: **main** branch, **(root)** directory  
5. Click **Save** ✓

### Step 3: Wait & Access (2 min)
Wait ~1-2 minutes, then visit:
```
https://echoTHE1.github.io/neonplay
```

✅ **Done!** Your site is live and unblocked!

## Troubleshooting (5 sec each)

**Blank page?**
→ Hard refresh (Ctrl+Shift+R) wait 2 minutes

**CSS/JS not loading?**
→ Check browser DevTools (F12 → Network tab)

**Ad blocker issues?**
→ Whitelist `github.io` domain or disable temporarily

**Games not working?**
→ Clear browser cache, try different browser

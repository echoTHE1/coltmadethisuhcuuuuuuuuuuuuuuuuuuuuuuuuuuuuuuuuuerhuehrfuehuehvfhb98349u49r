## 🚀 Quick Start

### 1. Deploy to GitHub Pages (30 seconds)

```bash
cd neonplay
git add .
git commit -m "Initial commit: NEONPLAY gaming hub"
git remote add origin https://github.com/YOUR_USERNAME/neonplay.git
git push -u origin main
# Enable Pages in GitHub Settings → Pages
# Visit: https://YOUR_USERNAME.github.io/neonplay
```

### 2. Test Locally (30 seconds)

```bash
# Python
cd neonplay && python3 -m http.server 8000

# Then visit: http://localhost:8000
```

### 3. Deploy to Netlify/Vercel (1 minute)

- Connect GitHub repo to Netlify/Vercel
- Auto-deploys on push
- URL provided instantly

## 🔧 Troubleshooting

### Particles not showing?
→ Check browser Canvas support (use Chrome if issue persists)

### Games not working?
→ Hard refresh (Ctrl+Shift+R) and check console (F12)

### Styles not loading?
→ Verify styles.css is in same directory as index.html

### Sound not playing?
→ Click sound toggle button first (browser autoplay policy)

See [DEPLOYMENT.md](DEPLOYMENT.md) for full troubleshooting guide
